# KaringX/ClashMi 服务商安全对接指南

## 为什么进行服务商对接

近期，海外直连入口被封、中国大陆中转线路被通报和拔线的风险持续增加。对服务商来说，真正危险的往往不只是代理协议本身，而是订阅链接、节点入口和面板信息被泄露。

一旦用户将订阅分享、倒卖，或订阅被第三方客户端、爬虫、采集平台收集，同一入口下的其他用户也可能受到影响。严重时，整条中转线路可能被通报、封禁或拔线。

目前常见的防护方式包括：

| 方案                                         | 优点                                                                     | 局限                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 封端（限制订阅仅向指定或官方客户端来源发放） | 降低订阅被第三方程序和爬虫收集的概率                                     | 用户必须使用官方客户端，第三方客户端用户会感到不便                     |
| 私有 DNS                                     | 节点域名不再依赖公共 DNS 解析                                            | 客户端配置复杂，小白用户不友好，仍可能因配置或传播造成泄露             |
| KaringX 服务商对接                           | 通过 App 登录/绑定、订阅代理、域名择优切换和消息通知尽力降低入口暴露风险 | 帮助减少订阅和入口裸奔带来的连锁风险，并提升入口变更时的处理与触达效率 |

服务商对接在不明显牺牲用户体验的前提下，极大降低订阅泄露、入口泄露和域名不可用带来的风险。

## 功能价值

### 降低订阅泄露风险

- 用户可通过服务商编码/别名和面板账号在 App 内登录或绑定，不必手动复制订阅链接。
- 订阅代理、User-Agent 和硬件指纹可减少异常访问与订阅地址直接暴露的机会。
- 隐藏订阅链接和节点详情可减少敏感信息展示。

### 兼顾安全和用户体验

- 用户不必自行配置复杂规则或额外插件。
- 支持 sspanel、v2board、xboard、remnawave、3x-ui、marzban 等常见面板。
- 私有 DNS、到期提醒和消息通知可由服务商统一配置，便于用户使用与维护。

### 提升服务可用性和品牌认知

- 域名择优切换和健康检测有助于应对可用域名变化。
- 订阅代理、域名配置和消息通知有助于服务商在入口调整时触达用户。
- 可展示服务商品牌 Logo、置顶订阅，或隐藏“获取流量”菜单。

这些能力旨在尽力降低订阅、域名和线路相关风险，并提升入口变更时的处理与触达效率。

---

## 适合哪些服务商

- 希望减少订阅链接在第三方客户端、爬虫或采集平台中传播。
- 希望降低单个用户泄露订阅后影响整组入口的风险。
- 正在使用或计划使用中国大陆中转、优质入口、备用域名等方案。
- 希望给小白用户提供比手动订阅更简单的官方入口。
- 希望在不完全封闭生态的前提下，提高官方客户端入口的使用比例。

> 安全边界：该功能通过降低泄露概率、缩小泄露影响，帮助服务商提升入口调整后的处理与触达效率；仍建议配合服务端风控、订阅权限控制和异常访问监控。

## 对接流程

1. 访问并注册 [KaringX 服务商管理后台](https://harry.karing.app/auth/login)。
2. 在后台创建服务商，提交服务商名称、主页链接、服务地域等基础信息；创建后会生成服务商编码/别名，即 `uniqid`/code。
3. 在基础信息页面的「Mi App」卡片点击「开始对接」。
4. 打开 `https://harry.karing.app/provider/binding/{服务商编码}`，将其中的 `{服务商编码}` 替换为上一步生成的 `uniqid`/code，设置“登录URL”即完成对接；接下去可根据自身需求定制下列分组配置并保存。

> 适用范围与版本：设置只影响通过 App “登录/绑定” 使用订阅的用户设备；
>     🤝Karing版本必须高于 `1.2.23.2602` ；
>     😼Clash Mi版本必须高于 `1.0.27.1301` ；



### 基础设置

| 字段     | 默认值/要求 | 说明                                                                   |
| -------- | ----------- | ---------------------------------------------------------------------- |
| 面板登录 | 开启        | 默认开启。                                                             |
| 面板类型 | 必填        | 可选 `sspanel`、`v2board`、`xboard`、`remnawave`、`3x-ui`、`marzban`。 |

### 订阅设置

| 字段                       | 默认值/要求 | 说明       |
| -------------------------- | ----------- | ---------- |
| 开启硬件指纹               | 关闭        | 默认关闭。 |
| 套餐到期提醒               | 开启        | 默认开启。 |
| 订阅 User-Agent (Karing)   | 留空        | 默认留空。 |
| 订阅 User-Agent (Clash Mi) | 留空        | 默认留空。 |
| 订阅代理                   | 关闭        | 默认关闭。 |

### 复写与 DNS

| 字段              | 默认值/要求 | 说明                                                                                                                                                                                                                                          |
| ----------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 关闭 APP 内置复写 | 关闭        | 默认关闭，仅 Clash Mi 可用。                                                                                                                                                                                                                  |
| 私有 DNS          | 留空        | 默认留空，仅 Karing 可用；以逗号分隔地址，允许的协议前缀为 `udp://`、`tcp://`、`tls://`、`https://`。输入形式示例：`udp://dns.example.com:53`、`tcp://dns.example.com:53`、`tls://dns.example.com:853`、`https://dns.example.com/dns-query`。 |

### 防泄露与安全

| 字段         | 默认值/要求 | 说明                                                                                                     |
| ------------ | ----------- | -------------------------------------------------------------------------------------------------------- |
| 隐藏订阅链接 | 开启        | 默认开启。开启之后，用户在 UI 界面看不到订阅链接，也就降低了被分享的可能。开发者模式除外。               |
| 隐藏节点详情 | 关闭        | 默认关闭。开启之后，用户在 UI 界面只能看到节点名称，无法查看、编辑节点详情。开发者模式和运行时配置除外。 |

### 智能域名切换

| 字段             | 默认值/要求    | 说明                                                           |
| ---------------- | -------------- | -------------------------------------------------------------- |
| 开启域名择优切换 | 关闭           | 默认关闭。                                                     |
| 备用面板域名     | 每行一个纯域名 | 每行一个纯域名。                                               |
| 域名健康检测 URI | 留空           | 默认留空。留空或以 `/` 开头，例如 `/favicon.ico`、`/healthz`。 |

### 展示与品牌

| 字段               | 默认值/要求 | 说明       |
| ------------------ | ----------- | ---------- |
| 订阅高亮置顶       | 关闭        | 默认关闭。 |
| 服务商 Logo URL    | 留空        | 默认留空。 |
| 隐藏“获取流量”菜单 | 关闭        | 默认关闭。 |

### 消息通知

| 字段         | 默认值/要求 | 说明                                     |
| ------------ | ----------- | ---------------------------------------- |
| APP 消息通知 | 关闭        | 默认关闭，仅发送给已登录或已绑定的设备。 |

## 使用建议

- 引导用户使用服务商编码/别名和面板账号在 App 内登录或绑定，减少原始订阅链接传播。
- 使用域名切换时，为备用面板域名逐行填写纯域名，并结合健康检测 URI 使用域名择优切换。
- 发生入口调整、域名变更或线路维护时，可通过订阅代理、域名配置和 APP 消息通知协助用户完成入口变更。
- 对高风险入口和中转线路，仍应配合服务端风控、订阅权限控制和异常访问监控。

订阅代理、域名配置和消息通知可帮助降低入口变更带来的影响，并提升处理与触达效率。

## 常见问题

**Q: 服务商对接如何帮助降低通报或封 IP 风险？**

A: 服务商对接可帮助降低订阅链接和入口信息暴露风险，并在入口变化时提升用户触达效率。结合服务端风控、订阅权限控制和异常访问监控，可让入口管理与用户沟通更顺畅。

**Q: 面板类型列表中没有我的系统怎么办？**

A: 请联系开发人员添加面板系统支持。Telegram: @ovowe @ElonWang

**Q: 域名如何填写和使用？**

A: 备用面板域名每行填写一个不带协议的纯域名。启用域名择优切换时可结合健康检测 URI；健康检测 URI 可留空，或填写以 `/` 开头的路径，例如 `/favicon.ico`、`/healthz`。
