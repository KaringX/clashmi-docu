# 机场FAQ

## 如何让Clash Mi兼容私有DNS？
### 方案A APP自动同步:
::: tip
- 在 `harry.karing.app` 注册服务商，完成“对接Clash Mi”设置，取消勾选 ☑️ “开启复写”
  - （可选）添加别名
  - 用户可直接使用在 ClashMi 上使用 `别名/编码 + 网站用户名、密码` 登录，APP 会自动同步配置完成设置。
:::

### 方案B 用户手动设置:
::: tip
- 用户手动取消 `复写`，导入配置时，“核心复写”选项选择“内置-不复写”
  - 也可在“核心设置”中选择“内置-不复写” 或 “DNS选项” 关闭复写。
:::
